This is a 28-message synthetic smoke dataset (four examples per category), not a measured accuracy claim or a representative personal-inbox benchmark. Add approximately 100 independently labeled, consented and redacted examples from the intended inbox before trusting automation. Keep holdout examples separate from prompt few-shot examples. Human overrides are stored in `classifications` with `source=human` and can inform curation, but should not automatically become ground truth without review.

Run `make eval` after configuring an LLM key and explicit cloud-processing consent. The CLI reports aggregate accuracy, per-category accuracy, a confusion matrix, model and prompt version. It exits nonzero below `--min-accuracy`. Use `--predictions predictions.json` for offline scoring of an ID-to-category mapping. CI runs live evaluation only on main-branch pushes when the OpenAI secret is configured; it prints an explicit skip otherwise.
